# Snake — terminal game

Simple terminal Snake game written in Rust using `crossterm`.

Run:

```bash
cd /home/josh/repos/snake
cargo run --release
```

Controls:
- Arrow keys to move
- `q` to quit

Game modes:
- Easy, Medium, and Hard provide preset arena sizes and snake speeds.
- Custom mode lets you adjust arena width, arena height, and snake speed.
- Use the arrow keys and Enter to navigate the mode and custom settings screens.
